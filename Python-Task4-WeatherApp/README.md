# Weather App Using Python

## Project Description
A Python-based Weather App that retrieves current weather information for a city using the Open-Meteo API.

## Features
- Search weather by city name
- Display temperature
- Display feels-like temperature
- Display humidity
- Display wind speed
- Display weather conditions
- Check multiple cities

## Technologies Used
- Python
- Requests Library
- Open-Meteo API

## How to Run
1. Install Python.
2. Install requests using `pip install requests`.
3. Run the application:

```bash
python weather_app.py
```
